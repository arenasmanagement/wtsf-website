# WTSF Website Asset Map
**West Tennessee State Fair — Pre-Implementation Photo & Video Reference**
*Art direction complete. Use this document to rename files, then hand off for implementation.*

---

## How to Use This Document

1. Locate each file in Google Drive using the **Current Filename** and **Folder** columns.
2. Download and rename using the **Suggested New Filename**.
3. Place all files in `/public/images/` (photos) and `/public/videos/` (videos).
4. Apply the **Implementation Notes** before uploading (crop, overlay, convert to WebP, etc.).
5. The **Master Table** at the bottom is the quick-reference for implementation.
